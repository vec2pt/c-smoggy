# smoggy

<p align="center">
<img src="doc/c-smoggy-00.png" alt="c-smoggy title image."/>
</p>

A simple tool for fetching air quality information. The data provider is [Open-Meteo](https://open-meteo.com/).

## Usage

```sh
# Basic usage
smoggy

# Specify city
smoggy "Nowa Słupia"
```
